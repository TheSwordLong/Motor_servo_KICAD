# 历史自检参数与残差变更

> 当前执行规则见 [自检手册](../Robot_电机自检.md)。

## 2026-09-27：每程通电上限调整为2秒

`ROBOT_SELFTEST_POWER_MS=2000U`，主循环和 SysTick 截止保护共用此值。去程与回程分别计时，不是固定转满2秒；去程达到3个FG或回程达到去程总计数时仍提前刹车。最大低电平占空比100‰、每10ms增加10‰、静止确认500ms和刹车后停止确认超时2000ms不变。整路总通电最多4秒，不包含余转等待。

延长时间不保证解决M4反馈不足；FG断线时也可能继续驱动至2秒上限，不能保证实际转角。首次验证必须确认机械空间。报文、协议版本2、Flash格式不变；需烧录本次新构建才生效，000F=2本身不能区分300ms与2秒版本。


### M4 自检原因 10：历史固件回位残差超限实例

旧判据的 2026-09-27 用户串口测试（新版不再按残差失败）：命令接受，但去程 5 个、回程 8 个 FG，最终残差 -3，超过 ±1 脉冲要求而失败。去程/回程记录时间为 6/10 ms，均为提前截止，不能据此验证 2 秒上限。完整报文、字段解码、故障查询与后续排查见[实测记录](Robot_自检验证记录.md#m4-return-error-20260927)。阶段 5 只表示结束；状态 4 且原因 0 才表示自检通过。


## 2026-09-27：残差仅记录的新判据

用户确认取消残差超限失败：去程和回程仍须在各自 2000 ms 内达到目标，停稳后记录有符号残差；任何可表示的残差数值本身不再触发原因10或故障7，也不阻止批量下一路。无反馈、脉冲不足、返回超时、捕获错误、其他通道异常活动、停止超时、位置越界、存储错误和取消处理保持不变。

残差寄存器 +2E/+2F、通信命令、Flash 格式和协议版本2保持不变；原因10只保留给旧固件记录解释。原本位置有效则成功后保留有效性，当前位置按实际计数保存，不强制回到原计数；原本位置无效仍保持无效；仅恢复绝对参考时需手动设零。响应自检通过不代表精确机械回位，不自动补转。

旧固件 M4 去程6、回程10、残差-4的实测失败仍是历史事实，新版在相同计数且无其他异常时应通过；不能将历史结果改写为新版实测成功。本次未烧录或远程试转。


## 单电机换接口与原因 10 排查

同一个电机换接口前先停机、断开电机电源再换线。非零关节标签必须唯一：从 M2 换到 M4 时，应在暂存配置中禁用 M2 并清除其标签，给 M4 设置标签和真实减速比，然后执行一次 CONFIG 并读回。只禁用旧通道而保留重复标签，仍可能导致配置被拒绝。M1→M2 同理；不要在电机未连接的接口反复进行角度测试。

顺序为：停止 → 清故障并确认不再出现 → 配置/保存并读回 → 单路自检 → 读取结果及往返详情 → 通过且停止后按需建立绝对零点（仅相对运动可跳过） → 核对有效位和保存状态 → 单次 MOVE → 读取状态、角度及保存状态。ZERO 会重定义当前位置，不能用于证明自检通过或机械问题已修复。

若结果原因仍为 10，先保存日志，核对当前构建目录、构建时间和实际烧录文件；当前源码不会仅因残差失败。详情中的返程时间 `000A` 与结果原因 10 不同。最新[本地测试](Robot_自检验证记录.md#local-ports-20260928)中 M2/M4 均为去程 5、返程 8、残差 -3，状态 4、原因 0。

# GD32F303VET6_MotorControl

GD32F303VET6四路机器人电机板：FG反馈、输出轴相对角度、独立方向/刹车、往返自检、Flash配置与位置保存、Modbus或CAN。ROS2维护源在ros2/，支持头部与左右臂双板控制。

## 当前规则

| 项目 | 当前行为 |
|---|---|
| 通道 | 固定M1～M4，报文0～3，ROS2 YAML1～4 |
| 参数 | 每路启用、role、516/290/82减速比、反相、减速前400～8000RPM，默认8000 |
| 通信 | 默认Modbus 115200 8N1；CAN标准帧500kbit/s，二选一 |
| 命令 | 协议2，完整命令直接执行，无A55A提交；0序号自动分配，非零去重 |
| MOVE | 固件相对输出轴0.1°，单次±360°，不自动清故障或设零 |
| 位置 | ZERO人工定义当前姿态；无效计数不用于绝对定位；固件相对MOVE可无有效零点 |
| 故障4 | 已提交有效减速比下累计非预期活动>10°报警；不是净偏移，未配置不报警 |
| 自检 | 每程10%/2s，反馈后按实计数反转尝试返回，残差只诊断；上电不执行 |
| 输出 | PWM高停止，BRAKE低制动；M3 BRAKE为PD2，DIR/BRAKE源码推挽 |
| 保存 | 运动前dirty，全部静止保存；dirty重启位置无效、不续跑 |
| ROS2 | angle_deg、limits_deg及度数状态，旧弧度兼容，JointState仍rad |

先读UID/版本/四路状态/保存→必要时自检并记录→按实际硬件CONFIG保存→读回→需要绝对参考时明确设零→小角度试转→核对完成、fault、brake及保存。
0序号丢应答不自动重发；正常应答仅表示接受。单线FG不能独立核验真实方向，上电早期保护不能保证复位前外部电平，机械限位与刹车保持仍需验收。

ROS2改动以ros2/为源，同步独立工程与远程；隔离域测试后恢复只读。2026-10-09度数接口三包构建、490个pytest通过见 [验证记录](docs/ROS2_度数接口验证记录.md)；本次文档整理未重跑这些构建或运动测试。
